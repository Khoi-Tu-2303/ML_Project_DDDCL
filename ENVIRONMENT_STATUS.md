# Trạng thái môi trường

Profile chính: Windows x86_64 / Python3.11.9 / PyTorch2.5.1 / CPU. Source tác giả TensorFlow tách biệt.

- Dependency input: requirements.in (pin trực tiếp).
- Transitive lock Windows/Python3.11: requirements.txt; generated by uv0.13.5 on Linux với target Windows, hashes đầy đủ. Không phải `pip freeze` của máy Windows đã train.
- Command resolve: `uv pip compile requirements.in --python-version 3.11 --python-platform windows --generate-hashes --output-file requirements.txt`.
- Môi trường author dùng README tác giả và phaseF, không cài chung TensorFlow vào venv chính rồi gọi là môi trường đã khóa.
- Same seed/environment/device repeat là kiểm tra Agent phải thực hiện ở phaseD. GPU/OS/framework khác có thể cho kết quả khác, cần track riêng.
- Môi trường creator hiện tại không phải Windows và chưa cài toàn bộ PyTorch stack; xem KIT_VALIDATION cho những kiểm tra đã thực sự chạy.

Nếu dùng Linux: generate `env/requirements-linux-py311.lock.txt` với `--python-platform x86_64-manylinux_2_28` (kiểm tra option của uv tại máy), rồi fresh-venv install/import/test; không áp lock Windows cho Linux. Torch trên Linux có thể resolve CUDA runtime dependencies dù chạy CPU; nếu dùng CPU-only index thì đó là lock profile riêng, ghi index và wheel source.
